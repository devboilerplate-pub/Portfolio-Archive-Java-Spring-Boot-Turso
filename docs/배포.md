# 프로젝트 배포 가이드 (Vercel 배포 분석 및 대안)

이 문서는 현재 구축된 Spring Boot 풀스택 애플리케이션의 배포 전략을 분석하고 가이드하기 위해 작성되었습니다.

## 1. Vercel 배포 가능 여부 분석

**결론부터 말씀드리면, 현재 상태의 Java Spring Boot 애플리케이션은 Vercel에 배포하는 것이 사실상 불가능하며 권장되지 않습니다.**

### ❌ 불가능한 이유 (Why not Vercel?)

1. **런타임(Runtime) 미지원**: Vercel은 주로 Node.js, Python, Go, Ruby 기반의 서버리스(Serverless) 함수와 Next.js, React 같은 프론트엔드 프레임워크 호스팅에 최적화된 플랫폼입니다. Java(JDK) 환경을 공식적으로 지원하지 않습니다.
2. **아키텍처 불일치**: Vercel은 요청이 들어올 때만 잠깐 실행되는 '서버리스 함수(Serverless Functions)' 아키텍처를 사용합니다. 반면 Spring Boot는 내장 톰캣(Tomcat)을 띄우고 애플리케이션 컨텍스트를 메모리에 상주시키며 요청을 처리하는 '상주형 서버(Long-running Server)' 방식입니다.
3. **콜드 스타트(Cold Start) 및 리소스 제한**: 비공식적인 커뮤니티 플러그인(`vercel-java`)을 억지로 사용하여 서버리스 환경에 배포하더라도, Spring Boot 특유의 무거운 초기 구동 속도(Cold Start) 때문에 Vercel의 무료 티어 함수 실행 시간 제한(일반적으로 10초)을 초과하여 타임아웃 오류가 발생하게 됩니다.

따라서 이 프로젝트에는 `vercel.json`을 생성하지 않는 것이 맞습니다.

---

## 2. Spring Boot에 적합한 대체 배포 플랫폼 (대안)

초보자 친화적이고, Java Spring Boot를 원활하게 호스팅할 수 있으면서 무료 티어(Free Tier)를 제공하는 클라우드 플랫폼들을 추천합니다. 

이 프로젝트(보일러플레이트)는 별도의 로컬 DB 구성 없이 Turso(외부 API)를 사용하도록 설계되었기 때문에, **앱 서버(웹 서버)만 배포하면 되는 아주 이상적인 형태**를 띠고 있습니다.

### 대안 1: Koyeb (강력 추천)
- **특징**: 설정이 매우 간편하고, 무료 티어 성능이 좋아 Spring Boot 앱을 띄우기에 넉넉합니다. Dockerfile 없이도 깃허브 레포지토리 연결만으로 자동 빌드(Buildpack)를 지원합니다.
- **배포 방법**:
  1. Koyeb에 가입 후 GitHub 저장소를 연결합니다.
  2. `Environment Variables` 항목에 `TURSO_DATABASE_URL`과 `TURSO_AUTH_TOKEN`을 입력합니다.
  3. Deploy 버튼을 누르면 자동으로 Gradle 빌드를 수행하고 배포가 완료됩니다.

### 대안 2: Render
- **특징**: 초보자들이 가장 많이 사용하는 무료 클라우드 중 하나입니다. 단점은 일정 시간 접속이 없으면 서버가 수면(Sleep) 모드에 들어가서, 다음 첫 접속 시 30초~1분 정도의 지연이 발생할 수 있습니다.
- **배포 방법**:
  1. Render Dashboard에서 'Web Service'를 생성하고 GitHub 저장소를 연결합니다.
  2. Runtime을 `Docker`가 아닌 `Java` 환경(Build Command: `./gradlew build`, Start Command: `java -jar build/libs/*.jar`)으로 설정합니다.
  3. `Environment Variables`에 Turso 환경변수 2개를 입력하고 배포합니다.

### 대안 3: Railway
- **특징**: 직관적인 UI를 제공하며 Koyeb과 마찬가지로 Nixpacks를 사용하여 설정 없이 코드를 바로 인식하고 배포해 줍니다. 
- **단점**: 완전 무료 티어가 폐지되어 매월 $5 한도 내의 일회성 크레딧(Trial)만 제공하므로 지속적인 무료 호스팅에는 적합하지 않을 수 있습니다.

## 3. 요약 및 권장 사항

이 프로젝트를 학습/연구용으로 포크(Fork)하여 배포하려는 초보자들에게는 **Koyeb**이나 **Render**를 이용한 배포를 가이드하는 것을 가장 추천합니다. 두 플랫폼 모두 깃허브 연결 후 `TURSO_*` 환경 변수 2개만 등록해 주면 클릭 몇 번만으로 완벽하게 배포가 끝납니다.
